# Projeto Final do Curso de Listas e Coleções de Dados do Curso da Alura

Simulador de cartão de crédito simples.

## 🧠 Conhecimentos utilizados
- Java
- POO
- Listas e Coleções do Java

## 📋 Funcionalidades
- Definine o limite do cartão
- Registra as compras (descrição + valor)
- Valida o saldo antes de aprovar
- Deduz o saldo a cada compra
- Encerra se saldo for insuficiente
- Exibe compras ordenadas por valor no final
- Exibe o saldo restante

## ▶️ Como executar
1. Clone o repositório
2. Abra no Eclipse
3. Execute a classe Main

## 📚 Aprendizados
Aprendi a como as listas podem ser utéis para armazenar quantias de informações do projeto.
